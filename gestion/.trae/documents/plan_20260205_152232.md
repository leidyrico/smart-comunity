Para aumentar el tiempo de ejecución y evitar errores de timeout al enviar correos masivos a los propietarios, realizaré los siguientes cambios:

1.  **Aumentar el límite global en la configuración:**
    *   Modificaré el archivo `config_timeout.php` para aumentar el `max_execution_time` de **300 segundos (5 minutos)** a **1800 segundos (30 minutos)**. Esto beneficiará a todos los procesos que utilicen esta configuración.

2.  **Forzar tiempo ilimitado en el proceso de envío:**
    *   Editaré el archivo `app/Http/Controllers/ReciboGastoComunController.php` para agregar `set_time_limit(0);` al inicio del método `asignarReciboATodosApartamentos`. Esto eliminará el límite de tiempo específicamente durante el bucle de envío de correos, asegurando que el proceso no se corte sin importar cuántos apartamentos sean.

### Archivos a modificar:
*   `gestion/config_timeout.php`
*   `gestion/app/Http/Controllers/ReciboGastoComunController.php`
